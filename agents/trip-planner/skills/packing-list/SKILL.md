# Packing list

1. Get the weather for the destination with get_weather.
2. Group the list under: Clothes, Toiletries, Tech, Documents, Extras.
3. Fit clothes to the forecast: name the expected temperatures and rain, then say what that means.
4. Count items by the number of days (e.g. "3 T-shirts" for three days).
5. Keep it under 25 items.
